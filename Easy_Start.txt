Semantic consistency monitor is now part of the core launch.
It compares confirmed/stable semantic landmarks against live D435 YOLO-depth object observations.
It is only a monitor/warning layer; it does not move the car and does not correct Cartographer.

New monitor topics:
/perception/semantic_localization_residual
/perception/health
/perception/semantic_residual_markers

Meaning:
- small residual: live object agrees with the stored map landmark
- medium residual: uncertain, trust it less
- large residual on one object: possible bad YOLO/depth observation
- large residual on several confirmed/stable objects: possible localization drift warning

QCar2 Perception Layer code comments
Added: 2026-05-20 13:47:02 EDT

Commented recent tuning directly in code:
- object_3d_estimator.py now explains why max_uncertainty_radius and max_marker_radius exist.
- semantic_landmark_mapper.py now explains why status and visibility are separate.

Reason:
Far YOLO detections can have weak/noisy depth, so uncertainty grows.
We keep that uncertainty useful for debugging and mapping, but cap marker display size so Foxglove stays readable.
Stable landmarks stay stable because that means long-term map confidence; visibility says whether the D435 sees them recently.

QCar2 Perception Layer permanent landmarking
Added: 2026-05-20 13:58:39 EDT

Permanent landmark behavior:
- Candidate landmarks are kept in live RAM memory so the next YOLO-depth observation has something to match.
- Confirmed landmarks are stronger live memory, but still not saved permanently by default.
- Stable landmarks are permanent semantic map landmarks and are saved into semantic_map.json.

Current default:
semantic_map.json saves only:
status == stable

Why:
Candidates are useful hypotheses, but they can be false positives or noisy depth hits.
Saving only stable landmarks keeps the permanent semantic map cleaner.

Association tuning:
- The mapper now uses XY distance for association by default.
- association_radius is now 0.80 m in the core launches.

Reason:
Signs and objects can have noisy estimated height/depth, so full XYZ gating can split one real object into many candidates.
XY gating makes repeated observations more likely to update the same landmark until it becomes stable.

QCar2 Perception Layer session semantic map
Added: 2026-05-20 15:42:04 EDT

semantic_map.json is now treated as a session overlay, not an eternal map.
On each core perception launch, semantic_landmark_mapper starts with an empty semantic map when reset_map_on_start is true.

Meaning:
- Cartographer map remains the localization/geometric map authority.
- semantic_map.json stores semantic landmarks discovered during the current run.
- Old stable semantic landmarks from a previous run are not reloaded by default.

Launch default:
reset_map_on_start: true

Use reset_map_on_start: false only when intentionally testing persistent semantic memory across runs.

QCar2 Perception Layer YOLO dead-zone mask
Added: 2026-05-20 15:43:50 EDT

semantic_yolo_detector now applies a pre-YOLO ignore polygon over the visible QCar body/dead image region.
This prevents YOLO from using that region for inference and helps stop false detections from becoming trash landmarks.

Debug display:
/perception/yolo/image_annotated draws the ignored region as a red transparent polygon with "NA" in the center.

Meaning:
NA = not available for YOLO inference.

QCar2 Perception Layer semantic marker topic split
Added: 2026-05-20 16:08:30 EDT

Semantic landmark markers are now split by meaning so Foxglove is easier to read.

Topics:
/perception/semantic_landmark_markers
  Stable landmarks only. This is the semantic map overlay for the current run.

/perception/semantic_hypothesis_markers
  Candidate and confirmed landmarks. This is working memory / debug hypotheses.

/perception/semantic_current_markers
  Only landmarks currently visible to the D435 semantic pipeline.

/perception/semantic_residual_markers
  Consistency monitor residual lines only. These are not landmark memory.

Meaning:
Stable map, live hypotheses, current observations, and residual checks are separate Foxglove layers now.
